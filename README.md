# Привет, меня зовут Анастасия 👋

Фронтенд-разработчик, создающий чистые, адаптивные и поддерживаемые веб-интерфейсы.

Я работаю с React, TypeScript, Redux Toolkit и современными инструментами фронтенд-разработки. Разрабатываю SPA-приложения с интеграцией REST API и WebSockets, роутингом, авторизацией, формами, централизованным управлением состоянием и протестированными пользовательскими сценариями.

## ✨ Обо мне

- 🔭 Прямо сейчас делаю адаптивный лендинг [F&B Botanica](https://github.com/afanassk/f-and-b), отрабатывая навыки верстки и стилизации.
- 📚 Читаю серию книг Кайла Симпсона *«Вы пока ещё не знаете JS. Познакомьтесь, JavaScript»*.
- 🌱 Прокачиваю инженерное мышление через **алгоритмы и структуры данных**.
- 👥 Умею работать в коллективе — помогала тимлиду вести команду из 10 фронтендеров на проекте [SkillSwap](https://skill-swap-46-4.vercel.app).
- 🎨 Уделяю особое внимание аккуратной адаптивной верстке (SCSS, БЭМ, Pixel Perfect), структурированному коду, рефакторингу и работе в команде.
